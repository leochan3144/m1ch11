      Section 2 · 11.1

      Continuous random variables

      Discrete variables use sums. Continuous variables use density and area.

      Watch out Density is not probability

      f(x) may be greater than 1. Probability is the area under the density curve over an interval, so it is always between 0 and 1.

      A continuous random variable連續隨機變量 takes values on an interval. Counts are usually discrete; measurements are usually continuous.

      Try it

      Classify each random variable

      Everyday examples

      The weight of an orange, annual rainfall, sea-water temperature and clinic waiting time are continuous. The number of patients already waiting is discrete.

      Probability density function

      For a continuous random variable \(X\) with p.d.f. \(f(x)\), probability is area:

      \[P(a\le X\le b)=\int_a^b f(x)\,dx\]
      Explore

      What area does each event describe?

      Key fact Why P(X = k) = 0

      The interval from k to k has zero width, so its area is zero. Therefore \(P(a\lt X\lt b)\), \(P(a\le X\lt b)\) and \(P(a\le X\le b)\) are all equal for a continuous variable.

      Definitions\[\mu=E(X)=\int_{-\infty}^{\infty}xf(x)\,dx\]\[\operatorname{Var}(X)=E[(X-\mu)^2]=\int_{-\infty}^{\infty}(x-\mu)^2f(x)\,dx\]\[\operatorname{Var}(X)=E(X^2)-\mu^2=\int_{-\infty}^{\infty}x^2f(x)\,dx-\mu^2\]

      Valid density

      \(f(x)\ge0\) for all \(x\), and \(\int_{-\infty}^{\infty}f(x)\,dx=1\).

      Linear changes still work

      \(E(aX+b)=aE(X)+b\)

      \(\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)\)

      Section 3 · 11.2A

      Normal distribution and its curve

      Notation alert

      Write \(X\sim N(\mu,\sigma^2)\): the second parameter is the variance, not the standard deviation.

      A normal p.d.f. is bell-shaped, symmetric about \(\mu\), and has its maximum at \(X=\mu\). Mean, median and mode coincide.

      Normal probability density\[f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac12(\frac{x-\mu}{\sigma})^2},\qquad -\infty\lt x\lt\infty,\ \sigma>0\]

      Shape

      Bell-shaped and symmetrical about \(X=\mu\).

      Maximum

      The curve peaks at \(X=\mu\); mean = median = mode = \(\mu\).

      Total area

      The whole area under the curve is 1.

      Different means

      Same variance: same shape, different central locations.

      Different variances

      Same mean: same centre, different spreads. Larger σ gives a lower, wider curve.

      Standard normal distribution

      \(Z\sim N(0,1)\), with mean 0 and variance 1.

      Section 6 · 11.2C

      Standardize any normal variable

      Standardization

      If \(X\sim N(\mu,\sigma^2)\), then

      \[Z=\frac{X-\mu}{\sigma}\sim N(0,1)\]

      Subtracting μ centres the curve at 0. Dividing by σ gives it unit spread. The probability area stays the same.

      Section 7 · 11.3

      Applications of normal distribution

      Every application uses the same core: define the variable, standardize, draw the region, then use the table. Later examples add conditional probability, binomial counts or mixtures.

      Strategy

      Five questions to ask

      1. What does \(X\) measure, and in what units?
      2. Are μ and σ known, or must two probability statements determine them?
      3. Which interval or tail is shaded?
      4. Does the question ask for a proportion, a boundary, or a parameter?
      5. Is there a second stage: conditional probability, several selections, or two types of object?
